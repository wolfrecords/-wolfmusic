WOLF MUSIC — ONLINE V3

Cette version corrige le problème de chargement de la V2 et améliore la réservation.

Nouveautés :
- Calendrier moderne en fenêtre, avec navigation mois par mois.
- Les dates passées sont désactivées.
- Sélection de date sans saisie manuelle.
- Les créneaux disponibles apparaissent sous forme de boutons.
- Les créneaux déjà confirmés ou bloqués sont exclus.
- Les erreurs Supabase sont maintenant affichées pour faciliter le diagnostic.
- La réservation utilise create_booking.

La clé intégrée est la clé PUBLISHABLE Supabase. Ne jamais mettre une clé secret/service_role dans le navigateur.

Pour tester : ouvre index.html.
